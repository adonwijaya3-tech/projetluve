Admin Dashboard

Akses dashboard dinonaktifkan sementara sampai autentikasi Supabase dan operasi admin sisi server terhubung.

Keamanan sebelum rilis
Dashboard lama memakai login palsu di browser dan data lokal, sehingga tidak aman untuk mengelola toko publik. Jangan gunakan kredensial demo lama. File demo lokal tersedia sebagai admindhasbor-demo-local.html hanya untuk pratinjau offline—jangan unggah file tersebut ke situs publik.

Langkah berikutnya: buat proyek Supabase, jalankan supabase/schema.sql, atur environment variables Netlify, lalu integrasikan login Supabase serta CRUD admin ke database.
